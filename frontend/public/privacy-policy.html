Privacy Policy — Self-Hosted Edition

Last updated: October 31, 2026

This is a self-hosted application. When you install Construction AI OS on your own server (via pip install, Docker, or VPS), all data you create — accounts, projects, BOQs, CAD files, costs — stays on your machine. The publishers of this software do not see, collect, or process any of it.

1. Who We Are

Construction AI OS is an open-source application (AGPL-3.0-or-later) maintained in this GitHub repository. It is based on the OpenConstructionERP project; the upstream copyright holders and the changes made in this distribution are named in the NOTICE and LICENSE files that ship with the source.

Questions about this distribution: open an issue in the repository above. If you operate this installation for a team or clients, your organisation is the contact for your users.

2. What This Policy Covers

This policy describes the privacy properties of the self-hosted application — the software you install and run on your own infrastructure. Whoever operates an installation is responsible for the privacy of its users.

3. Data You Create In Your Local Installation

When you register an account, create projects, import CAD files, or build BOQs in your self-hosted installation:

  • Your data is written to your database (PostgreSQL, embedded or external).
  • Files you upload (PDFs, drawings, models) live on your filesystem or your S3 bucket.
  • Authentication tokens (JWT) are issued by your server and never leave it.
  • The application does not phone home, carries no telemetry, and sends no analytics. Inspect the source — there are no outbound network calls except those listed in §5.

Under GDPR the operator of an installation is the Controller. The publishers of this software are neither a Controller nor a Processor of your project data.

4. Personal Data Collected By The App

The application stores user-account fields (email, name, optionally company / role) in your local database — purely so users can log in and see their name in the UI. These fields are your data, governed by your privacy policy if you operate the app for others.

5. Outbound Network Calls

The application makes outbound HTTP calls only in these well-defined cases. All are optional, user-triggered, or off by default:

CaseDestinationTriggered when
AI features (estimation, classification)The AI provider you configure (OpenAI / Anthropic / Google / a self-hosted endpoint)You set your own API key and call an AI feature. Prompts go to your chosen provider.
Geocoding (map search)The geocoding service you configure (OpenStreetMap Nominatim by default)You search for an address or place on a map view.
CAD converter binariesgithub.com/datadrivenconstruction releasesFirst-time install of a CAD format, downloading the converter executable.
Cost-database snapshotsgithub.com/datadrivenconstruction releasesYou click "Install region" in the cost-data import screen.
Translation dictionariesiate.europa.eu, dl.fbaipublicfiles.com and configured mirrorsYou explicitly download a dictionary or terminology dump in the translation tools. Opt-in; nothing is fetched during normal operation.
Update check (optional)pypi.org or this repository's releasesYou run the upgrade command or pip install --upgrade.

None of these send your project data anywhere. They only fetch software / data to your server.

6. No Tracking, No Analytics

The app does not embed Google Analytics, Mixpanel, Sentry, FullStory, or any other analytics or session-replay tools. No tracking pixels. No advertising cookies. No cookie consent banner is needed because only essential session storage is used (JWT token, language and appearance preferences).

7. Your Rights If You Run This App For Others

If you operate Construction AI OS as a service for end users (your team, your clients), you are the Controller under GDPR / CCPA / equivalent regimes. You should publish your own privacy policy for those users and handle data subject requests yourself. The app provides built-in tools to support this:

  • Account export (JSON / CSV / Excel) for data portability.
  • Account deletion that removes all associated personal data.
  • JWT short-lived tokens + bcrypt password hashing for security.
  • Source-available code (AGPL-3.0-or-later) for independent security audit.

8. Changes

This policy may be updated. Changes ride along with new releases of Construction AI OS and are visible in the CHANGELOG. The "Last updated" date at the top reflects the current version.

9. Contact

Questions about the software's privacy properties: open an issue in the source repository. This page is a template for self-hosted installations; operators serving end users should publish their own policy with their own contact details.
